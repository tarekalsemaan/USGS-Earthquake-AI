# USGS-Earthquake-AI

Projet de Machine Learning réalisé à partir des données sismiques de l’USGS.

Le projet permet d’analyser les séismes et de faire des prédictions concernant :

* les zones de risque ;
* le PGA ;
* les dommages ;
* les actions à prendre ;
* les pertes économiques.
